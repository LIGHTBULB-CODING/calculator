# Calculator

## What it will do
    Addition            8+2 --> 10
    Subtraction         8-2 --> 6
    Multiplication      8*2 --> 16
    Division            8/2 --> 4
    Root                sqrt8 --> 2root2
    Power               8^2 --> 64

    Take complex inputs involving multiple operations, and output the result.

## How to run it

    navigate to calculator.py, found in the current working directory

    Enter the full calculation string. Eg: 5(3+1/2)
    The program will recognise the use of brackets, and employ BIDMAS to calculate the result.
    The program will output the result.
