# Requirements
##    Operations:
        Addition            8+2 --> 10
        Subtraction         8-2 --> 6
        Multiplication      8*2 --> 16
        Division            8/2 --> 4
        Root                sqrt8 --> 2root2
        Power               8^2 --> 64

##    The Calculator Must:
        Have a GUI
        Register inputs such as /, *, ^, ect...
        Be able to run more complex calculations, such as finding roots
        Run entire lines of operations using BIDMAS. E.g. 8(9+2) = 88
        Find missing terms
        Be able to catch exceptions
            Division by 0
            Numbers exceeding python's integer limit
            NAN inputs
